WINDOWS CLIENT

Connect to RoverOS

RoverOS searches automatically for the MiniPC named RoverOS-Server. Join its Wi-Fi or connect to the same local network.

First-time MiniPC setup

Enter the certificate fingerprint and one-time pairing code printed by the MiniPC bootstrap installer. Wi-Fi credentials are sent only over the fingerprint-verified encrypted setup connection and are not saved on this computer.

The MiniPC must be running RoverOS. This desktop app connects to it; it does not install the server or database on this computer. No IP address is required.
