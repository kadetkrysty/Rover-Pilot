# Bundled application fonts

The web app bundles the Latin WOFF2 subsets of its existing Rajdhani,
Orbitron, and JetBrains Mono fonts. Local assets keep the same typography
available in the Windows desktop app, Android app, and offline client without
requesting Google Fonts at runtime.

The fonts are licensed under the SIL Open Font License, version 1.1. The
complete license notices are included beside the files.
